# K线练习助手

> A股全市场随机选股 K线交易训练工具

## ✨ 功能特性

- **全市场随机选股** — 覆盖 200+ A股真实股票，每次训练随机抽取
- **多周期K线** — 支持日线、周线、月线，含完整历史K线浏览
- **仓位交易** — 半仓/全仓买入卖出，键盘快捷键操作（B/M + 1/2）
- **技术指标** — MACD、KDJ、RSI 三大技术指标实时叠加
- **游戏化资金系统** — 初始资金 ¥100,000，破产(≤¥1,000)/暴富(≥¥100M)判定
- **资产收益曲线** — 训练过程实时绘制净值变化
- **复盘模式** — 训练结束后查看交易标记（买卖点箭头+成本线）
- **明亮现代UI** — 清爽高级的交互界面

## 🚀 快速开始

### 运行数据服务器（可选）

```bash
python server.py
```

服务器在 `http://localhost:8765` 启动，用于获取真实股票数据。

### 直接使用

直接用浏览器打开 `index.html` 即可开始训练。系统会自动使用内置股票池和示例数据。

## ⌨️ 操作说明

| 快捷键 | 功能 |
|--------|------|
| `B` → `1` | 半仓买入 |
| `B` → `2` | 全仓买入 |
| `M` → `1` | 半仓卖出 |
| `M` → `2` | 全仓卖出 |
| 滚轮/触控板 | 缩放K线 |
| 拖拽 | 平移K线 |
